Google Sheets
Step 1 — Create a blank Google Sheet
Go to sheets.google.com, create a new blank spreadsheet. Leave it empty — the script adds headers on first run.
Step 2 — Paste the Apps Script
In your sheet click Extensions → Apps Script. Delete any existing code, paste the script below, then click Save (💾).
Step 3 — Deploy as Web App
Click Deploy → New Deployment. Click the gear ⚙ next to "Select type" → Web App. Set Execute as: Me and Who has access: Anyone. Click Deploy, authorize with your Google account, then copy the Web App URL.
Step 4 — Paste URL & Test
After saving, click "Send Test Row" — it opens a new tab. If your sheet gets a new row labelled "TEST", everything is working. If the tab shows an error, your script isn't deployed correctly (re-check Step 3).
